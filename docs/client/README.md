# Client guides

These guides are for company administrators and HR users. Settings and employee records belong to the company you are signed into. Sign into the correct company before making changes.

| Guide | Use it for |
| --- | --- |
| [Configure leave policies](leave-settings.md) | First-time setup, every setting, company-specific policies and later changes |
| [Record leave and holiday/off-day rewards](leave-workflows.md) | Requests, approvals, carry-forward, balance adjustments and rewards from Attendance Days |
| [Understand attendance, reports and payslips](leave-attendance-reports.md) | Which numbers change, what reports mean, worked examples and resolving blocked payroll |

For a new company, start with the configuration guide. For an existing company, select a start date after your closed payroll periods and existing leave commitments, then verify opening balances before switching employees. Existing annual allowances continue for leave categories/dates not enrolled in the new settings. Adding starter categories does not disable your older categories.

Compensatory leave means paid leave earned by working on an eligible holiday or rostered off day. It is awarded from **Attendance Days**; there is no separate compensatory page. The menu currently labels the attendance section **Attendance**.

Deployment, database design and developer verification are documented separately in [Developer guides](../developer/README.md).
